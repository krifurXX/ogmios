# Advanced Search Strategies

## Effective Search Query Construction

### Recency Optimization
Always include recent years to prioritize current information:
```
"technology best practices 2024 2025"
"framework migration guide 2024"
```

### Specificity Levels

**Broad Overview:**
```
"React hooks overview"
"Docker container basics"
```

**Focused Investigation:**
```
"React useEffect cleanup function best practices"
"Docker multi-stage build optimization"
```

**Problem-Specific:**
```
"Next.js 14 app router data fetching patterns"
"PostgreSQL connection pooling Node.js"
```

## Parallel Query Design

### Pattern 1: Aspect Decomposition
Break topic into logical aspects:
```
Query 1: Core functionality
Query 2: Best practices
Query 3: Common pitfalls
Query 4: Tools and ecosystem
```

### Pattern 2: Depth Levels
Layer from general to specific:
```
Query 1: High-level overview
Query 2: Implementation details
Query 3: Advanced patterns
Query 4: Performance optimization
```

### Pattern 3: Perspective Diversity
Gather different viewpoints:
```
Query 1: Official documentation
Query 2: Community tutorials
Query 3: Case studies
Query 4: Critical analysis
```

## Domain-Specific Strategies

### Technical Documentation
- Search official docs site directly
- Include version numbers
- Look for migration guides
- Check GitHub repos for issues

### Academic Research
- Use Zotero MCP if available
- Search academic databases
- Include methodology keywords
- Look for systematic reviews

### Market Research
- Include "comparison", "vs", "alternatives"
- Search for user reviews and sentiment
- Look for analyst reports
- Check community discussions

### Current Events
- Include "news", "latest", "2024"
- Search multiple news sources
- Look for primary sources
- Cross-reference timelines

## Source Validation Techniques

### Quick Credibility Check
1. Check domain authority (official sites, .edu, .gov)
2. Verify author expertise (bio, credentials)
3. Review publication date (recent = better)
4. Cross-reference with other sources

### Red Flags
- No publication date
- Unknown author
- Heavily biased language
- No sources cited
- Outdated information presented as current

## Synthesis Best Practices

### Structure Your Findings
1. **Executive Summary**: 2-3 sentences
2. **Key Findings**: 7-10 bullet points
3. **Detailed Analysis**: Per domain/aspect
4. **Recommendations**: Actionable next steps
5. **Sources**: Full attribution

### Cross-Reference Validation
When sources disagree:
- Note the divergence
- Seek additional sources
- Evaluate source credibility
- Mark as "requires verification"

### Confidence Assignment
- All sources agree + official docs = **High**
- Multiple sources agree = **Medium**
- Single source or conflicting info = **Low**

## Time Management

### 1-2 Minute Research
- 30s: Query decomposition
- 60s: Parallel search execution
- 30s: Quick synthesis

### 5-10 Minute Research
- 1m: Scope definition
- 6-8m: Task agent execution
