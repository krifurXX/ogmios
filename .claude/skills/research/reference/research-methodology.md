# Research Methodology Guide

## Research Philosophy
Fast, reliable results over complex orchestration. Pragmatic approach to information gathering.

## Core Principles

### 1. Speed + Quality
- Target 1-2 minutes for most queries
- Parallel execution of search queries
- Multi-source validation
- High-confidence findings prioritized

### 2. Source Quality
**Prioritize:**
- Official documentation
- Reputable technical blogs
- Community resources (GitHub, Stack Overflow)
- Recent content (2024-2025)

**Verify:**
- Author credibility
- Publication date
- Cross-reference with other sources

### 3. Confidence Levels
Mark all findings with confidence indicators:
- **High**: Multiple reputable sources, official docs
- **Medium**: Single reputable source or community consensus
- **Low**: Limited sources, requires verification

## Research Modes Comparison

### Quick Research (Default)
- **Time**: 1-2 minutes
- **Tools**: WebSearch (parallel queries)
- **Best for**: Most research needs, technical docs, best practices
- **Approach**: 3-4 parallel queries, synthesis

### Extensive Research
- **Time**: 5-10 minutes
- **Tools**: Task agent with researcher subagent
- **Best for**: Deep-dive, multi-domain, high-stakes decisions
- **Approach**: Iterative research, comprehensive analysis

## Query Decomposition Patterns

### Technology Research
1. Core concepts and architecture
2. Best practices and patterns
3. Performance and optimization
4. Security considerations

### Competitive Analysis
1. Market landscape and players
2. Feature comparison
3. Pricing and business models
4. User sentiment and reviews

### Current Events
1. Latest developments
2. Expert opinions
3. Impact analysis
4. Future implications

## Source Attribution Best Practices

Always include:
- Source title and URL
- Publication date (if available)
- Author/organization (if credible)
- Confidence level for each finding

Example:
```
**Source**: Official Documentation - Cloudflare Workers
**URL**: https://developers.cloudflare.com/workers/
**Confidence**: High
```

## Integration with Knowledge Management

Research outputs should flow to:
- Scratchpad (working directory) during research
- History archive for permanent storage
- Zotero (if academic sources)
- Arkivet Cards (if extractable insights)

See workflows for specific file management patterns.
