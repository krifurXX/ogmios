# Extensive Research Workflow

## Overview
Deep-dive research using Task tool for comprehensive, multi-domain analysis.

## When to Use
- Complex multi-domain topics
- Academic literature reviews
- Comprehensive competitive analysis
- Stakeholder presentations
- PhD research projects

## Time Investment
5-10 minutes (requires user confirmation)

## Workflow Steps

### 1. Scope Definition
Clearly define:
- Research question(s)
- Target depth level
- Required domains
- Success criteria

### 2. Task Agent Launch
Deploy researcher subagent with:
- Clear research objectives
- Domain boundaries
- Quality requirements
- Time constraints

### 3. Multi-Source Investigation
Agent conducts:
- Multiple search iterations
- Source cross-referencing
- Deep documentation review
- Pattern identification

### 4. Comprehensive Synthesis
Combine findings:
- Executive summary
- Detailed findings per domain
- Cross-domain insights
- Evidence and sources
- Gaps and limitations

### 5. Quality Review
Verify:
- Source credibility
- Finding completeness
- Logical coherence
- Actionability

## Expected Output
Comprehensive multi-domain research report suitable for high-stakes decisions.

## Voice Announcement
```
🎯 COMPLETED: [SKILL:research] Comprehensive research analysis complete
🗣️ CUSTOM COMPLETED: In-depth findings delivered
```
