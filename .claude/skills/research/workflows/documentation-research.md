# Documentation Research Workflow

## Overview
Research technical documentation using WebFetch for deep-dive into specific resources.

## When to Use
- Reviewing official documentation
- Learning specific APIs or frameworks
- Implementation planning
- Deep technical understanding needed

## Workflow Steps

### 1. Identify Target Documentation
Use WebSearch to find:
- Official documentation URLs
- Tutorial resources
- API references
- Community guides

### 2. Deep Documentation Review
For each critical resource, use WebFetch:
```
WebFetch(url, "Extract key concepts, APIs, and best practices")
```

### 3. Structured Extraction
Capture:
- Core concepts and architecture
- API methods and parameters
- Configuration options
- Best practices and patterns
- Common pitfalls
- Code examples

### 4. Integration Planning
Map findings to:
- Implementation requirements
- Technology stack fit
- Integration points
- Potential challenges

### 5. Documentation Summary
Create concise summary with:
- Quick start guide
- Key capabilities
- Critical configuration
- Links to detailed docs

## Expected Output
Actionable documentation summary ready for implementation.

## Voice Announcement
```
🎯 COMPLETED: [SKILL:research] Documentation review complete
🗣️ CUSTOM COMPLETED: Technical docs analyzed
```
