# Parallel Research Workflow

## Overview
Execute fast, multi-source research using parallel WebSearch queries and synthesis.

## When to Use
- Technology research and best practices
- Competitive analysis and market research
- Current events and news research
- Fast overviews (1-2 minutes)

## Workflow Steps

### 1. Query Decomposition
Break the research topic into 3-4 distinct aspects:
- Core concepts and fundamentals
- Best practices and patterns
- Common challenges and solutions
- Tools and ecosystem

### 2. Parallel Execution
Launch all WebSearch queries simultaneously:
```
WebSearch("Topic best practices 2024 2025")
WebSearch("Topic performance optimization")
WebSearch("Topic security considerations")
WebSearch("Topic development workflow")
```

### 3. Source Evaluation
For each result:
- Verify source credibility (official docs, reputable blogs, community)
- Check recency (prefer 2024-2025 content)
- Note confidence level (high/medium/low)

### 4. Synthesis
Combine findings into structured report:
- Overview section
- Key findings (7-10 points)
- Best practices
- Recommendations
- Sources with URLs

### 5. Delivery
- Formatted markdown report
- Source attribution
- Confidence indicators
- Next steps

## Expected Output
Comprehensive research report in 1-2 minutes with multi-source validation.
