# Conduct Usability Testing Workflow

## Overview
Test designs with real users to identify usability issues and gather feedback.

## Workflow Steps

### 1. Planning
- Define objectives (what to test)
- Identify target users
- Create test tasks
- Prepare prototype
- Recruit participants (5-8 users)

### 2. Test Script
Create script with:
- Introduction and consent
- Background questions
- Task scenarios
- Post-task questions
- Wrap-up

### 3. Conduct Tests
- One-on-one sessions (30-60 min)
- Think-aloud protocol
- Observe, don't guide
- Take notes on:
  - Task completion
  - Time to complete
  - Errors and confusion
  - User comments

### 4. Analyze Results
- Identify patterns across users
- Severity ratings (Critical/High/Medium/Low)
- Quantitative metrics (success rate, time)
- Qualitative insights (quotes, observations)

### 5. Report Findings
- Executive summary
- Methodology
- Key findings (with severity)
- User quotes
- Recommendations
- Screenshots/videos

### 6. Iterate Design
- Prioritize issues (critical first)
- Redesign problem areas
- Validate fixes with follow-up testing

## Test Metrics

**Quantitative:**
- Task success rate
- Time on task
- Error rate
- Number of assists needed

**Qualitative:**
- User satisfaction (1-5 scale)
- Ease of use perception
- Frustration points
- Delight moments

## Remote Testing Considerations
- Use screen sharing tools
- Record sessions (with permission)
- Send prototype links in advance
- Clear instructions for setup
