# Create Wireframes Workflow

## Overview
Design low-fidelity wireframes to establish layout and user flow before visual design.

## When to Use
- New feature design
- User flow planning
- Layout exploration
- Stakeholder alignment

## Workflow Steps

### 1. Understand Requirements
- User needs and goals
- Business objectives
- Technical constraints
- Content requirements

### 2. User Flow Mapping
- Entry points
- User actions
- Decision points
- Exit points
- Error states

### 3. Sketch Low-Fidelity
- Paper sketches or digital rough drafts
- Focus on layout, not visuals
- Multiple variations
- Quick iterations

### 4. Create Digital Wireframes
Elements to include:
- Navigation structure
- Content hierarchy
- Interactive elements (buttons, forms)
- Placeholder content
- Annotations for interactions

### 5. Review and Iterate
- Stakeholder feedback
- User testing (if possible)
- Refine based on feedback
- Document decisions

## Wireframe Fidelity Levels

**Low-Fidelity:**
- Boxes and placeholder text
- No colors or styling
- Focus: Layout and structure

**Mid-Fidelity:**
- More detailed content
- Actual UI elements (buttons, inputs)
- Still grayscale
- Focus: Interaction patterns

**High-Fidelity:**
- Near-final content
- Detailed UI components
- May include some styling
- Focus: Final layout validation

## Tools
- Figma, Sketch, Adobe XD
- Balsamiq (low-fidelity)
- Paper and pencil (initial sketches)
