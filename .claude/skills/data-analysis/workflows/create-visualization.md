# Create Visualization Workflow

## Overview
Design clear, informative data visualizations following best practices.

## Chart Selection Guide
- **Trends over time**: Line charts
- **Comparisons**: Bar charts
- **Distributions**: Histograms, box plots
- **Relationships**: Scatter plots
- **Proportions**: Pie charts (use sparingly)
- **Multiple variables**: Heat maps, faceted plots

## Workflow Steps

### 1. Understand the Story
- What insight to communicate?
- Target audience technical level
- Context and purpose

### 2. Choose Chart Type
- Match visualization to data type
- Consider cognitive load
- Prioritize clarity over complexity

### 3. Design Visualization
- Clear title and labels
- Appropriate scales
- Color choices (accessibility)
- Legend placement
- Annotations for key points

### 4. Refine and Polish
- Remove chart junk
- Enhance readability
- Test with target audience
- Export in appropriate format
