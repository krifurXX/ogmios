# Statistical Methods Reference

## Descriptive Statistics

### Measures of Central Tendency
- **Mean**: Average value
- **Median**: Middle value (robust to outliers)
- **Mode**: Most frequent value

### Measures of Dispersion
- **Standard Deviation**: Spread around mean
- **Variance**: Average squared deviation
- **Range**: Max - Min
- **IQR**: Interquartile range (Q3 - Q1)

## Inferential Statistics

### Hypothesis Testing
1. Formulate null (H0) and alternative (H1) hypotheses
2. Choose significance level (α = 0.05)
3. Calculate test statistic
4. Determine p-value
5. Make decision (reject/fail to reject H0)

### Common Tests
- **t-test**: Compare means of two groups
- **ANOVA**: Compare means of multiple groups
- **Chi-square**: Test categorical associations
- **Correlation**: Measure linear relationships
- **Regression**: Model relationships between variables

### Confidence Intervals
- 95% CI: Range likely containing true parameter
- Interpretation: "95% confident true value in [a, b]"

## Data Visualization Principles

### Chart Types
- Line: Trends over time
- Bar: Categorical comparisons
- Scatter: Relationships
- Histogram: Distributions
- Box plot: Distribution with outliers
- Heat map: Matrix data

### Design Principles
1. Clear title and labels
2. Appropriate scales
3. Legend when needed
4. Minimize chart junk
5. Accessibility (color blind safe)
6. Context and annotations

- Sampling bias

### Solutions
- Imputation strategies
- Outlier detection and handling
