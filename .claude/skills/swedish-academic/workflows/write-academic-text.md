# Skriv Akademisk Text Workflow

## Översikt
Skapa välstrukturerad svensk akademisk text enligt universitetskonventioner.

## Arbetsflöde

### 1. Förberedelse
- Klargör syfte och målgrupp
- Samla källor och material
- Skapa disposition
- Definiera nyckelbegrepp

### 2. Struktur
**Avhandling/Uppsats:**
- Introduktion
- Teoretiskt ramverk
- Metod
- Resultat
- Analys
- Diskussion
- Slutsats

**Artikel:**
- Abstrakt
- Introduktion
- Metod
- Resultat
- Diskussion
- Referenser

### 3. Skrivprocess
- Akademisk distans (undvik "jag")
- Formellt språk
- Tydliga argument
- Källhänvisningar
- Begreppsanvändning

### 4. Källor och Referenser
Harvard-systemet (GU):
- I text: (Andersson 2024, s. 15)
- Referenslista: Andersson, P. (2024) *Titel*. Ort: Förlag.

### 5. Granskning
- Språklig korrekthet
- Argumentationslogik
- Källhänvisningar kompletta
- Formell stil genomgående

## Röstmeddelande
```
🎯 COMPLETED: [SKILL:swedish-academic] Akademisk text färdigställd
🗣️ CUSTOM COMPLETED: Texten klar
```
