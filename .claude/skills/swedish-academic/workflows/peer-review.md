# Granska Akademisk Text Workflow

## Översikt
Systematisk granskning av svensk akademisk text.

## Granskningsaspekter

### 1. Struktur och Disposition
- Logisk uppbyggnad
- Tydlig röd tråd
- Balans mellan delar
- Kapitelövergångar

### 2. Innehåll och Argumentation
- Tydlig problemformulering
- Teoretisk förankring
- Metodisk stringens
- Resultatatredovisning
- Analys och tolkning
- Välgrundade slutsatser

### 3. Språk och Stil
- Akademisk svenska
- Formellt register
- Begreppsanvändning
- Meningsbyggnad
- Ordval

### 4. Källor och Referenser
- Tillräcklig källanvändning
- Aktuella källor
- Korrekt citering
- Fullständig referenslista
- Harvard/APA korrekt

### 5. Tekniska Aspekter
- Formatering enhetlig
- Rubriknivåer konsekventa
- Tabeller och figurer numrerade
- Fotnoter korrekta

## Feedback-struktur
- Styrkor (vad fungerar bra)
- Förbättringsområden (konkreta)
- Prioritering (vad viktigast)

## Röstmeddelande
```
🎯 COMPLETED: [SKILL:swedish-academic] Granskning genomförd
🗣️ CUSTOM COMPLETED: Granskning klar
```
